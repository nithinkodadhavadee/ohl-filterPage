# 15: Collapsible Subjects facet

**What to build:** The Subjects list is long and noisy, so it collapses and expands on its own, defaulting to collapsed and remembering its state for the session. While collapsed it still shows what is selected.

**Blocked by:** None (can start immediately)

**Status:** done (pass 2)

- [ ] The Subjects facet collapses and expands independently of the filter panel.
- [ ] It is collapsed by default.
- [ ] Collapse state is remembered for the session and is not encoded in the URL.
- [ ] While collapsed it shows the selected count, the first two selected names, and "+N more" when applicable.
- [ ] Expanding shows the full plain checkbox list with counts; keyboard and assistive technology supported.
