# 14: Collapsible filter panel

**What to build:** The whole filter section can be collapsed and expanded, defaulting to expanded and remembering its state for the session, so a Patron can reclaim screen space without losing active filters.

**Blocked by:** None (can start immediately)

**Status:** done (pass 2)

- [ ] A control collapses and expands the entire filter section.
- [ ] The section is expanded by default.
- [ ] Collapse state is remembered for the session and is not encoded in the URL.
- [ ] The control exposes its state to assistive technology and works with keyboard.
- [ ] Collapsing does not clear or alter active filters.
