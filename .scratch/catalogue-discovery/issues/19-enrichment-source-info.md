# 19: Enrichment source info affordance

**What to build:** Everywhere a Rating, Subject or page count appears, an "i" affordance explains where the value came from — the enrichment source — and that it may be sparse or mismatched. It applies in the grid, table and detail view.

**Blocked by:** None (can start immediately)

**Status:** needs-triage

- [ ] Rating, Subjects and page count each carry an inline "i" control in grid, table and detail view.
- [ ] Hovering or focusing it names the enrichment source and notes that values may be sparse.
- [ ] One shared component supplies the affordance and wording.
- [ ] It is keyboard-accessible and does not block the surrounding interaction.
